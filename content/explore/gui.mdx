## 为什么它很重要

这是大多数人每天都在接触、但却很少能准确理清的 Windows 组成部分。它解释了为什么一个已登录的会话、一个桌面、一个窗口和 shell 相互关联却又并非同一种事物。

## 思维模型

GUI 栈不仅仅是 'Explorer'。Windows 构建交互式会话，将它们附加到窗口站和桌面，然后通过专用的子系统来管理窗口、菜单、绘图和输入。

## 工作原理

1.  1创建一个用户会话并将其连接到一个交互式窗口站。
2.  2该窗口站包含如 Winlogon 和 Default 这样的桌面。
3.  3会话中的进程创建 USER 和 GDI 对象，用于表示窗口、菜单、光标、字体和绘图状态。

## 关键术语

Window station

一种可安全控制的对象，包含桌面以及共享的 GUI 资源，如剪贴板和原子表 (atom table)。

Desktop

一个逻辑的显示和输入表面，包含窗口、菜单和钩子 (hooks)。

USER/GDI

核心 GUI 对象家族，用于 Windows 中的界面元素和图形资源。

## 为什么 UAC 或 Ctrl+Alt+Del 会改变你看到的画面

Windows 可以在同一个会话内切换可见的桌面，这就是为什么安全登录或用户同意界面感觉像是进入了一个独立的环境，而不是仅仅弹出了一个普通窗口。

## 常见误区

桌面并不是 shell，shell 也不等同于整个 GUI 系统。Explorer 建立在更底层的会话、窗口管理和图形基础架构之上。
