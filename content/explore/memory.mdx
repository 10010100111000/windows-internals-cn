## 为什么这很重要

Windows 内存行为解释了崩溃、速度变慢、隔离，以及为什么一个进程不能轻易安全地读取另一个进程的内存。

## 心智模型

程序不使用原始 RAM 地址工作。它们在 Windows 映射、保护和换入换出的虚拟地址空间中工作。

## 深入一层

为在打开子主题前需要更多精确细节的读者提供的额外细节。

*   Commit charge 追踪承诺的虚拟内存；物理 RAM 使用是一个单独的约束。
*   Superfetch (SysMain) 和文件缓存与进程工作集竞争 RAM。

## 它是如何工作的

1.  1每个进程都有自己的虚拟地址空间。
2.  2Windows 跟踪这些区域的映射和保护。
3.  3内存管理器决定什么留在内存中，什么可以被换出。

## 关键术语

Virtual address space

进程使用的私有逻辑地址映射。

Working set

目前常驻在进程的物理内存中的页面集。

Page file

当内存内容被换出时使用的由磁盘支持的存储。

## 带有许多选项卡的浏览器

每个进程看到的是看起来像巨大的私有内存空间，但 Windows 仅映射当前实际需要的页面。

## 常见误解

虚拟内存不是假内存。它是允许 Windows 隔离、保护和有效地管理真实物理内存的抽象。
