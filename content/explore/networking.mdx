# 网络

Windows 如何将数据通过 TCP/IP 协议栈、过滤层和端点 API 进行传输。

## 30秒速览

应用程序使用 Winsock；内核通过 AFD 和 tcpip.sys 路由 sockets，其下方是过滤层 (WFP/BFE) 和 NDIS 适配器。

## 为什么它很重要

现代 Windows 高度依赖网络：身份验证、更新、域成员身份、云应用以及远程管理全都依赖于网络协议栈。

## 思维模型

网络是另一条分层流水线：顶端是应用程序 API，中间是协议栈，底端是适配器和驱动。

## 示意图

点击高亮区域了解该层级并深入阅读相关内容。

Application / Winsock

用户模式应用使用 Winsock。系统组件可以使用 Winsock Kernel (WSK) 来避免额外的用户/内核态转换。

## Windows 基础组件

可在任务管理器、资源管理器或者文档中查到的名称与路径。

*   Filetcpip.sys
    
    TCP/IP 协议驱动
    
*   Fileafd.sys
    
    Winsock 的辅助功能驱动 (Ancillary Function Driver)
    

## 深入一层

给希望在打开子主题前获取更精确信息的读者提供额外细节。

*   双栈 (dual-stack) 共享接口；loopback 和 vSwitch 端口是特殊情况。
*   WFP callouts 可以在多个层级进行检查，而无需替换 tcpip.sys。

## 工作原理

1.  1应用程序使用 sockets 和更高层的 API 请求网络通信。
2.  2TCP/IP 协议栈将这些请求转化为协议操作。
3.  3下层组件和驱动最终通过物理或虚拟接口传输数据包。

## 关键术语

Socket

用于网络通信的端点抽象。

TCP/IP 协议栈

Windows 中用于 Internet 协议的核心网络实现。

WFP

Windows Filtering Platform，用于检查和控制网络流量。

## 连接到一个网站

一个看似简单的浏览器操作，实际上跨越了 DNS、sockets、TCP 状态、过滤层和适配器驱动。

## 常见误区

网络并非独立于 Windows 的其余部分；安全、服务、驱动以及用户态 API 全都参与其中。
